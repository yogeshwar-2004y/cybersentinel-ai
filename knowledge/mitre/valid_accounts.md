# Valid Accounts

## Attack overview
An attacker can reuse legitimate credentials to access services. Successful login records must be evaluated in behavioral and authorization context.

## Indicators
New devices, unexpected geography, changed session patterns, unfamiliar privileged actions, and impossible concurrent activity.

## Detection
Correlate MFA results, device posture, source networks, session lineage, and normal access patterns. Consider VPN and travel effects.

## Mitigation
Use phishing-resistant MFA, short-lived privileges, conditional access, credential hygiene, and reviewed session revocation.
