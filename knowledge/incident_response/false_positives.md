# False Positive Triage

## Attack overview
Statistical rarity indicates difference from a reference distribution, not necessarily a security threat. Scheduled work and environment changes often create anomalies.

## Indicators
Approved maintenance, known scanners, scheduled bulk transfers, configuration mistakes, and new legitimate services.

## Detection
Check change calendars, asset owners, source systems, and independently verified authorization. Record the reason for classification.

## Mitigation
Close with an audit note, tune baselines only with trusted data, and keep recurrent patterns observable.

## MITRE ID
No direct technique asserted. Require behavioral evidence before assigning ATT&CK.
